# 智慧树看课助手（Ubuntu 版）

无人值守看智慧树（知到）视频课：自动答题、播完切下一课、掉线续播、到点开播、到量停播。

脚本负责判断（识别弹题、决定切课、记录时长），外挂负责真鼠标点击（页面里合成出来的点击智慧树不认）。跑在一台 Ubuntu 桌面机上，用 Chromium 的远程调试接口（CDP）驱动。

脚本下载：[最新版](https://github.com/heizhuyutou/zhihuishu-autostudy/releases/latest/download/智慧树弹题自动答题.user.js)

## 目录

| 文件 | 作用 |
| --- | --- |
| `智慧树弹题自动答题.user.js` | 主脚本，以扩展内容脚本方式注入（`world: MAIN`，与页面同世界） |
| `ubuntu/manifest.json` | 扩展清单（MV3），加载 `~/zhs-ext` 用 |
| `ubuntu/zhs_clicker_linux.py` | 真鼠标外挂。HTTP 服务 `127.0.0.1:8971`，收到指令用 CDP 发操作系统级点击 |
| `ubuntu/supervise.sh` | 看守：浏览器挂了重开、页面跑偏拉回、外挂停了补起 |
| `ubuntu/cdp.py` | 远端调试小工具（读页面状态、执行 JS、重载），排查用 |
| `ubuntu/启动学习页.sh` | 手动打开课程页 |
| `ubuntu/安装到ubuntu.sh` | 首次部署 |
| `ubuntu/zhs-clicker.service` | 外挂的 systemd 用户服务（`Restart=on-failure`） |
| `旧mac版/` | 旧的 macOS 版文件，仅存档，不再使用 |

## 一、装脚本

扩展方式加载，不用装油猴：

```bash
bash 安装到ubuntu.sh
```

它把 `~/zhs-ext/`（脚本 + manifest）和 `~/.local/share/zhs-clicker/`（外挂 + 看守）放好。装完手动做一次：

1. 在那个 Chromium 里登录一次智慧树，勾上「保存密码」。凭据存在 Chromium 密码管理器里，脚本不碰密码
2. `systemctl --user start zhs-clicker.service` 起外挂
3. 开课程页（`启动学习页.sh`，或者让 supervise.sh 自己开）

外挂服务**不开机自启**（`systemctl --user disable zhs-clicker.service`），页面和浏览器也不自启。这套东西只在需要看课的时候才该跑。

> 改了脚本要重启浏览器才生效：内容脚本在扩展加载时就缓存了，热替换文件没用。

## 二、角标

右下角角标是运行状态：

```
zhs v1.18.6 看视频 | env✓ | 外挂✓ | 今日 5:05/28:34
        ↑动作       ↑环境   ↑外挂    ↑今日进度
```

常见状态：`等 08:17 开播`（没到点）、`今日已看满 28:34`（到量停播）、`需登录`（登录过期，停手等你）、`外挂不通`（真点击通道断了，自动答题会等它回来）。

## 三、弹题：真鼠标作答、真鼠标关闭

弹题组件对页内合成事件一律忽略——完整鼠标序列、`element.click()`、直接设 `input.checked`、直接调 Vue 组件方法，五种打法实测全无效。所以作答只走外挂的真鼠标一条路。

**答题策略**：站点不给「做对了」的反馈，弹题也不计成绩，所以一路点到「对」没有意义：

| 题型 | 做法 |
| --- | --- |
| 单选题 / 判断题 | 随机挑一个选项，点一次，关闭（`CFG.randomPick`，false = 固定点第一个） |
| 多选题 | 每个选项各点一次，关闭 |
| 旧版播放器（页面自带答案） | 直接点那个答案 |

流程：算坐标 → 先 `/move` 过去用 `:hover` 验证坐标对不对 → 才让外挂点击 → 等 3~6 秒（人味）→ 收工并关闭。

- 答完的「关闭」同样走真鼠标，关不掉就换下一个关闭控件（文字按钮 → 关闭图标 → 右上角 X），试完还关不掉就放着不动，**绝不重复作答、不对着坐标反复点**
- 外挂不可用时**一次页内点击都不发**，角标写「请你手动作答」，题留给你点（弹题不计成绩，代价两秒），绝不代替你关弹窗
- 安全闸：窗口没聚焦只移动不点击；点击前一刻复核目标还在；坐标用 `:hover` 现场验证，验证通过才点

## 四、切课

**目录和弹题是同一套远程插件渲染的**，所以切课也先用真鼠标点课时条目，2 秒没动静再补一发合成点击（有些目录项本来就是普通 DOM 按钮），仍然切不过去才判定点不动。

**进页面先定位**：站点每次打开都从第一节开始，顺序切会把已看完的又播一遍。所以进页面先找目录里第一个没看完的课时直接跳过去（当前这节没看完时不打断）；切课时也优先选没看完的。

**判据是「有没有时长」，不是行名里的字**：

| 行 | 时长 | 判定 |
| --- | --- | --- |
| `2.4.7 中国武装力量的装备 00:20:13` | 有 | 视频课时 |
| `平时测试` / `第三章 战争史与军事思想` / `3.1 孙子兵法` | 无 | 跳过 |

- 主判据：文本里带 `00:20:13` 这样的时长才算课时（一条带时长的都没有时才退回全体）
- 排序加权：带时长 +4、class 里带 `video` +2、没看完 +8，越像该看的越优先
- 完成标记：条目里有 `time_icofinish` 图标 = 已看完，跳过
- 兜底词表（测验/测试/考试/题目/练习/作业/问卷/讨论/答疑/实验/直播/公告/回放/期中/期末）只在这行既没时长也没 `video` 类时才用来跳过，避免误杀课名自带这些字的真课时

**目录滚动**：真鼠标按屏幕坐标点，目标滚出可视区就会点歪。所以点之前先把目标滚到中间（找最近的 `overflow-y: auto/scroll` 祖先），等滚动稳定再点；目标坐标必须在视口内，否则一律不点。

**跨章推进（三层兜底，每次成功都清账）**：目录里确实没有可点的下一课时时（典型原因：下一章被折叠，课时没渲染进 DOM），依次试：站点自带的「下一节」按钮（真鼠标点）→ 展开后面的章节标题行（先点箭头，没效果再点整行）→ 往下滚触发懒渲染再扫。

> 切课成功后死条目黑名单、章节展开记录、滚动预算、按钮冷却全部清零。否则后一章会继承前一章的旧账，表现是「每到新的一章又跳不过去」。

点完验证真的切过去了（`.current_play` 移动 / 视频源变化 / 进度归零），30 秒没切成就把这条拉黑改点后面那个真课时；黑名单 3 分钟后作废，避免一次偶发失败被永久跳过。

## 五、每天看多久

| 选项 | 行为 |
| --- | --- |
| 不限时 | 一直看下去 |
| 每天随机 28–35 分钟 | 每天首次打开抽一个时长，当天固定 |
| 自定义 N 分钟 | 学校要求变了改这个数 |

**计时口径**：只算视频实际播过的进度（`currentTime` 在走才累加）。弹题、切课、缓冲的时间天然不计，拖进度条不算（一次跳太多不认）。

看够了自动暂停，不再续播、不再切课，角标写 `今日 12:34/30:00 已停`。想多看？手动按播放不拦，只是角标会显示已超。计数存浏览器本地，按当天日期记，关页面、刷新、重启浏览器都接着算，跨零点自动清零。

## 六、掉线、卡住会叫你

| 情况 | 反应 |
| --- | --- |
| 登录过期（冒出登录框 / 跳到登录页） | 角标写「需登录」，停手不动，系统通知 + 响一声 |
| 保活请求被跳到登录页 | 同上（提前发现票据失效） |
| 视频 8 分钟没进度 | 通知，写明停了几分钟 |
| 恢复正常 | 自己接着看 |

同一类消息 10 分钟内只叫一次（脚本侧按稳定键去重，外挂侧再按消息形状去重，数字变化不会绕过去）。

**会话保活**：智慧树的 cookie 全是会话级，关浏览器必掉登录。脚本空闲时随机 6–14 分钟发一次同源请求，尽量不让票据过期。长期停机后还是要人工登录。

**滑块验证不做自动拖**：腾讯防水墙按轨迹判人机，脚本硬拖等于给风控送把柄，账号风险不值。过期了人工拖一下，十秒钟。

## 七、看守

- **浏览器**：挂了 20 秒内重开，10 分钟最多 3 次
- **页面跑偏**：公告按钮会把课程页带去主站，连续两次发现就拉回。外挂不在时走 CDP 开新标签兜底
- **外挂**：8971 端口没人监听就 `systemctl --user restart`（60 秒冷却）

到量停播时**不退外挂**：以前「到量就收摊」会把外挂关掉，而没有任何东西负责拉起，第二天自动答题、切课、拉回页面全退化。现在只停播，外挂留着。

## 八、定时相关的功能是定制项

下面这些按我自己的作息配的，不是通用功能，别人用请自己改：

| 功能 | 默认 | 改法 |
| --- | --- | --- |
| 每日开播 | 08:00–08:30 之间随机一个时刻，当天固定、跨天重抽 | 面板「开播时间」，或 `CFG.startAt`（基准）+ `CFG.startJitter`（随机窗口分钟数，0 = 固定时刻） |
| 每日观看上限 | 随机 28–35 分钟 | 面板选「自定义」填两个数，或 `WCFG.mode` |
| 到量之后 | 只停播，不退外挂、不再切课 | — |
| 空闲保活 | 6–14 分钟随机 | `keepWarm()` 里的 `warmGap()` |
| 何时才按播放 | 到点前只看着不按播放 | 角标写 `等 08:17 开播` |

到点之后当天不再受时间限制，晚上想补看照样续播。

## 九、常用开关（脚本开头 CFG）

| 开关 | 默认 | 说明 |
| --- | --- | --- |
| `helper` | true | 真鼠标通道；false 就只能人工作答 |
| `randomPick` | true | 单选/判断题随机挑一个选项 |
| `autoClose` | true | 答完脚本点关闭；false = 只作答、关闭交人工 |
| `startAt` | `'08:00'` | 每日开播基准时刻，`''` = 不限 |
| `startJitter` | 30 | 开播随机窗口（分钟） |
| `stallMin` | 8 | 视频多久没进度提醒一次，0 = 关掉 |
| `helperPort` | 8971 | 外挂端口 |
| `tick` | 1500 | 主循环间隔(ms) |
| `debug` | false | 控制台打印全程日志 |

## 十、Ubuntu 部署细节

跑在 `chiang@192.168.123.172`（Ubuntu 22.04，全天开机，自动登录、关锁屏）。Mac 上最大的变数是睡眠/锁屏错过开播，这台机器没有这个问题。

| 位置 | 作用 |
| --- | --- |
| `~/.local/share/zhs-clicker/` | 外挂、看守脚本、日志 |
| `~/zhs-ext/` | 脚本本体（当扩展加载，改完要重启浏览器） |
| `~/zhs-profile/` | 专用 Chromium 配置目录，**登录态在这**，别删 |

浏览器启动参数，每条都有原因：

| 参数 | 为什么 |
| --- | --- |
| `--no-proxy-server` | 那台机器的系统代理指向 FlClash，出口是国外 IP；用境外 IP 刷课不划算，直连（家宽）更稳 |
| `--ozone-platform=x11` | 会话是 Wayland，xdotool 点不进原生 Wayland 窗口，走 XWayland 才行 |
| `--autoplay-policy=no-user-gesture-required` | 早上没人碰它也能自己播 |
| `--disable-background-timer-throttling` 等三条 | 窗口在后台不降频，答题/切课节奏不变慢 |
| `--password-store=basic` | 自动登录的会话里系统密钥环锁着，用默认存储会导致密码自动填失败。代价：密码存本地配置目录（混淆不是加密），自家机器才这么做 |

## 十一、排查

```bash
tail -f ~/.local/share/zhs-clicker/supervise.log     # 看守日志
journalctl --user -u zhs-clicker.service -f          # 外挂日志
python3 cdp.py                                       # 页面当前状态
```

| 现象 | 原因 |
| --- | --- |
| 角标 `外挂不通` | 本机 `curl http://127.0.0.1:8971/ping` 看看；supervise.sh 会自动重启它，等 20 秒 |
| 角标 `需登录` | 登录过期，去那个 Chromium 里登一次 |
| 角标 `窗口未聚焦` | 页面不在前台，切回去它就自己动 |
| 什么都不发生 | 角标版本号对不对？改完脚本有没有重启浏览器 |
| 每天重复看已看完的课 | 完成标记被站点改了（`time_icofinish`），看 `firstUnfinished()` |

站点改版会破坏选择器，表现为切课失败或答不上题。
